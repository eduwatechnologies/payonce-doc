---
title: "Introduction"
description: "Conventions used across the PayOnce API."
---

- **Base URL:** `https://api.payonce.com.ng/api/v1`
- **Auth:** `x-api-key` header
- **Format:** JSON request and response bodies
- **Network IDs:** `MTN`, `AIRTEL`, `GLO`, `9MOBILE`

Data, cable and exam purchases accept either a `packageCode` (recommended, human-readable) or an internal `planId`.
