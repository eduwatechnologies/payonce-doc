## Quick start

<Steps>
  <Step title="Get your API key">Copy your live key (or a `test_` key for sandbox) from your PayOnce dashboard.</Step>
  <Step title="Make a request">
```bash
curl -X POST https://api.payonce.com.ng/api/v1/airtime \
  -H "x-api-key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"phone":"08012345678","networkId":"MTN","amount":100}'
```
  </Step>
  <Step title="Handle the response">A successful call returns `success: true` and a `data.transactionId`.</Step>
</Steps>
